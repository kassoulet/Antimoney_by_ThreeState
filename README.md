# 3s-money (Three State, "antimoney", 64k) - web port, work in progress

`cd web && python3 -m http.server` then open the page: 512x384 canvas shown at 4:3, play/pause and seek bar (seek = set the audio clock; the video is a function of it).

## Status (honest)
| Part | State |
|---|---|
| Music | **Recording, not a port.** `web/assets/music.ogg` = 179.5 s (one pass of the 28 orders) of the original tracker synth run under Unicorn through an "ideal 25 ms DirectSound thread" (`re/emu.py`). The synth itself is not ported. The original loops at 179 s. |
| Scene script | Decoded (`re/NOTES.md`): 60 commands at 0x415250 fired by the tracker position (order<<8 \| row); row times in `web/assets/rows.json`. Drives the player (`web/fx/compose.js`: enable flags, slot-13 image index, palette level, rebuilt from the position so seek is pure). Check: `node re/fxcheck_compose.mjs` (needs `re/fbs`). |
| Slot 3 (star; orders 0-2 and 14-16, params 6/7 wired) | **Bit-exact** (`web/fx/fx03.js`, noise off): the warp table equals the original's memory (0 of 196608 words differ) and the line texture equals the output of the original routine 0x401000 under Unicorn (0 differing bytes of 65536, 10 clocks, both text-flag modes and the fixed-length mode; `python3 re/oracle_slot3.py out.json; node re/fxcheck_slot3.mjs out.json`). The old 0.6% residue was a port bug (119 line iterations, not 120) plus missing f32 rounding. Against the golden frames the picture is slot 3 + slot 24 grain: 0 pixels outside the grain range (`node re/fxcheck03.mjs`, needs `re/fbv`, not committed). Palette fade matches. The text overlay (mode 7) is not ported. |
| Slot 24 grain | Approximate (`Math.random`): the original uses `rand()` added per frame. |
| Slot 13 (images, orders 12-14) | Ported (`web/fx/fx13.js`): 4 images dumped from the emulator, saturating add. Gold >= image on ~100% of pixels; slot 11 (3D) on top is missing. |
| Palette level | Slot 0/3 rules exact; slots 15 and 18 now **derived** from the code (formulas above; against the golden frames they are offset by the unknown run clock: e.g. 138 vs 166 at 0x1620, 185 vs 175 at 0x1a1f); slot 4 is `rand()%100+100` per the code (random); the 11/13 era level is now derived (`slot11.js` `level`). |
| Slot 12 (3D snake walkers + 171 additive cubes, orders 8-11) | Frame logic ported (`web/fx/slot12.js`), wired into the compositor (`compose.js`, replayed from the enabling command on the 40 ms grid, seeded rand so cube placement differs from the original run). Model data (vertices, faces, grid, cube list, walker records, angles) is **identical** to the Unicorn run for frames 1-40 (`node re/fxcheck_s12model.mjs`, oracle `re/oracle_slot12.py`). Near-plane clip (0x40a18b) ported in `engine3d.js` (`clipPoly`, `queueFaces`), single-precision x87 emulated with `Math.fround` after every op (the reference emulator runs the FPU at 24 bits). Pixels: **0 differing bytes on every checked frame** (1-40, 100-105, 250, 400; model data identical too) against the Unicorn run with the same seeded rand/clock; walkers outside the grid are handled by a padded grid buffer. Palette/scene-level stats vs golden `fbs` N=240..320: white fraction follows the same decline (99.9% -> 84% gold, 99% -> 73% ours, ours has more overlap); not cube for cube. |
| Slot 5 (rotating textured icosphere, FOV from tracker) | **Bit-exact vs Unicorn, slot 24 grain OFF while comparing (grain stays in the port)**: `web/fx/slot5.js` (generator 0x40a979 n=4 r=150: 162 vertices / 320 faces / UVs identical, gradient texture 0x408510 0 of 65536 bytes differ, 40 random frames 0 differing bytes; `re/oracle_slot5.py`, `re/fxcheck_slot5.mjs`). Wired in `compose.js`. Against the golden run the full composite only agrees on 65-94% of pixels (slot 22 glow not exact, fitted palette, clock). |
| Near-plane clip 0x40a18b, face UVs | Fixed: `clipPoly` also interpolates env UV and face UVs. `mul`/`apply`/`camera` in `engine3d.js` now round every op to f32 (1-2 level diffs gone). Face types 0 and 1 exact to frame 250 (grain off). |
| Slot 4 (1024 text-mask particles, orders 6-7) | **Bit-exact vs Unicorn** (`web/fx/slot4.js`, grain off while comparing, grain stays in the port): sprite texture, init particle table (0 of 5120 ints differ) and 30 frames (0 differing bytes). The oracle uses a synthetic mask/overlay because the GDI text is blank under the emulator; the player draws a canvas-rendered "3" mask (Arial bold 255 px, the original's string at 0x41109c; `compose.js` `setMask`, approximation of the GDI glyph); placement uses a seeded rand. `python3 re/oracle_slot4.py o.json 30; node re/fxcheck_slot4.mjs o.json`. |
| Thick line brush (slot 18) | Bit-exact vs Unicorn (`line(..., brush=true)` in `tri.js`, `BRUSH=1 python3 re/oracle_line.py`). |
| Slot 15 (voxel terrain, orders 22-23) | **Bit-exact vs Unicorn, grain off** (`web/fx/slot15.js`): the 256x256 map (init 0x407020, 0 of 65536 bytes differ), the 0x708-entry cos/sin tables, the renderer 0x406e70 (36 random clocks, 0 differing bytes) and the palette level `ftol(sin(dt*0.001)*60+160)`, all exact (`python3 re/oracle_slot15.py o.json 30; node re/fxcheck_slot15.mjs o.json`). Wired in `compose.js` with the derived level; the map comes from a seeded rand (differs from the original's), `dt` is counted from the last disabled frame on the 40 ms grid. |
| Slot 18 (3 Hermite wire curves + words, orders 24+) | **Bit-exact vs Unicorn, grain off, text strips synthetic in the oracle** (`web/fx/slot18.js`): control points 0x404bbc, spline 0x4055c6, camera look-at matrix (0x409aaf, case roll 0), brush lines, 300 vertices, picture (0 differing bytes over 38 frames at random clocks and tracker positions) and the palette ramp `min(255, ftol((pos-0x1a00)*2.5+100))` (`python3 re/oracle_slot18.py o.json 30; node re/fxcheck_slot18.mjs o.json`). The words "work" / "consume" / "sleep" (GDI Impact 160, blank in the emulator) are approximated by canvas text in `player.js`. |
| Other slots | Not ported: slots 10, 14, 16, 23 (3D engine scenes 10/14, GDI-text effects 16/23). Text (Impact/Arial via GDI) is blank in the golden run, so it can only be approximated. Slot 14 needs the 300-walker graph; slot 10 (sprite blobs, init 0x4021a0, frame 0x402290, blit 0x402510) is disassembled but not ported; 16 and 23 not decoded.
| Slot 11 (102-mesh scene, keyframe camera) | **Exact vs Unicorn** (`web/fx/slot11.js`, `re/oracle_slot11.py`, `re/fxcheck_slot11.mjs`: camera floats, level, pixels, 30 frames, 0 differing bytes). Face type 199 = flat 0x82 SET triangle (0x403d30), added to `scene3d.js`. The meshes are an emulator dump (`web/assets/slot11.bin`); the loader is not ported. In the composite the start clock has a fitted +400 ms offset. |
| Slot 17 | **Exact vs Unicorn** (`web/fx/slot17.js`, `re/oracle_slot17.py`, `re/fxcheck_slot17.mjs`, 18 frames; rand is the seeded LCG, so the real run differs by its seed). | |
| Slot 22 (glow/zoom post-process) | Ported (`web/fx/fx22.js`), checked against the original routine under Unicorn (`re/oracle22.py`, `re/fxcheck22.mjs`): **bit-exact vs the oracle** for S 100..256, F 0.07..1.0 (the old mismatch was a missing f32 rounding in the LUT, `trunc(f32(i*f))`, not MMX junk). The residue vs a real run is the unknown register state of mm1..3 byte 0. Orders 18-20 now agree 90-99% with the golden frames. |
| Shared 3D engine (slots 4, 5, 10, 11, 12, ...) | **Partial hand port**, `web/fx/tri.js` + `web/fx/engine3d.js` + `web/fx/scene3d.js`: triangle filler and line drawer (Cohen-Sutherland + Bresenham, thin line only; bit-exact vs Unicorn), angle tables, matrix helpers, normals, projection (within 1 f32 ulp), face queue + depth sort, and the per-object pass wired together (`renderScene`: face types 6 triangle and 3 wireframe). Checked against real slot 12 frames run under Unicorn (`re/oracle_slot12.py`, `re/fxcheck_s12.mjs`): bit-exact on small scenes, 0 differing bytes up to frame 400 (about 130 cubes) once projection is rounded to f32 after every op and the clip is in. Near-plane clipping is ported (3-vertex faces). Face types 0/1 (textured triangles, `texTri` = 0x40b130 in `tri.js`, bit-exact vs Unicorn on random triangles: `re/oracle_textri.py`, `re/fxcheck_textri.mjs`) are wired in `scene3d.js` and match a real slot 12 run whose cube material was patched to type 0/1 (`T01=1 python3 re/oracle_slot12.py ...`, `re/fxcheck_s12.mjs`): 0 differing bytes on frames 5-60, 124 of 141564 lit bytes at frame 150 (textured faces crossing the near plane are dropped, their clipped UVs are not ported). NOT ported: clip of faces with more than 3 vertices, and the frame logic / geometry generators of slots 10, 11, 14, 16, 17, 23 (slots 4, 5, 15, 18 are ported, the brush is in `tri.js`). Slot 12's frame logic is in `slot12.js`. Table in `re/NOTES.md`. |
| Video/audio offset | Video clock = audio + 800 ms (guess from the golden run; machine dependent in the original). |

## Files
`re/` reverse-engineering (unpack, Unicorn harness, notes), `web/` player, original `3s-money.exe` untouched.

## Write-ups on the site

The write-ups are published as HTML next to the player (`web/writeups/`, generated from `WRITEUP-*.md` and the referenced `figures/`; needs pandoc). After editing a write-up, regenerate with:

```
../tools/mkwriteups.sh . web    # shared script: demoports/tools/mkwriteups.sh REPO_DIR PUBLISH_SUBDIR
```
